# Minecraft mods

Small, self-contained NeoForge mods written for the packs played here. Each folder is a
standalone Gradle project (Java 21, NeoForge ModDev).

| Folder | What it does |
|---|---|
| [`certus-quartz-ore/`](certus-quartz-ore/) | **Certus Quartz Ore** (`certusore`) — puts AE2's removed certus quartz ore back into worldgen for Minecraft 1.21.1 / ATM10: stone + deepslate, plus rare charged variants. |
| [`certus-budding-ore-datapack/`](certus-budding-ore-datapack/) | Datapack-only alternative to the mod above: generates **flawed budding certus quartz** underground, so certus keeps growing like AE2 intends but without meteorite hunting. No loader, no jar. |
